# Домашнее задание №4
## Условие задачи
Учёный проверяет гипотезу о 3 числах. Гипотеза подтверждается, если каждое из трех экспериментально полученных чисел (A,B,C) кратно трем. Запишите условие подтверждения гипотезы. 
## 1. Алгоритм и блок-схема
### Алгоритм
1. **Начало**
2. Ввести три целых числа 'A', 'B', 'C'.
3. Проверить условие:
   - `(A % 3 == 0) && (B % 3 == 0) && (C % 3 == 0)`
4. Если условие выполняется, вывести:
   - `Гипотеза подтверждается`
5. Иначе вывести:
   - `Гипотеза не подтверждается`
6. **Конец**
